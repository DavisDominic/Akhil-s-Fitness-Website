Design System V5.1 · Mobile first · 375px

Build fitness that lasts.

Charcoal-to-black surfaces, one lime-yellow signal, angled slash shapes, thin trace lines and condensed athletic type. Built for a three-page trust-and-trial site that people reach by scanning a QR code on their phone.

Case rule

Uppercase is for Display and H1 only, 8 words or fewer. Longer headings, FAQ questions and body use sentence case.

Minimums

09 / Imagery

Real people, real places.

The PRD’s proof is human, so the imagery is too. Photography carries trust; the line motifs are only a light accent around it.

Look

Natural light, honest expressions, real gyms. Slight contrast lift and a neutral grade; grayscale is optional for atmospheric backgrounds only, never for people the visitor must recognise.

Never

Stock athletes, before/after body comparisons, filters that hide faces, or a client photo without consent.

Delivery

AVIF/WebP with a JPEG fallback, explicit width and height, lazy-load below the fold, hero image preloaded. Always provide alt text for meaningful images.

Graphic accents

Slash stack, trace line, and the signal panel. Use one per screen behind or beside large type. Not on every card or button.

Placeholder rule

Until real photos exist, use the neutral frame with a caption of the shot needed. Do not use stock people. Every photo slot has a no-photo fallback (initials avatar, or the graphic accent).

11 / Motion & accessibility

Energy, not noise.

Motion signals state or hierarchy. It never delays a form.

Recommended

150ms for controls, 220ms for accordion and menu, 400ms for section reveals. Opacity and small translate only. Respect prefers-reduced-motion.

Avoid

Continuous decorative animation · large parallax · hover-only meaning · page transitions · anything that slows form completion.

Counters. The 4+ / 50+ / 2,400+ numbers may count up once on first view. Final value must be in the HTML for no-JS and reduced motion.
Accessibility checklist

✓ WCAG AA contrast (measured, see Color)
✓ Visible focus ring on every interactive element
✓ 44px minimum tap targets
✓ Semantic heading order
✓ Labelled fields; errors tied to fields
✓ Keyboard-accessible accordion and menu

✓ State is never color alone
✓ Alt text for meaningful images; empty alt for decorative
✓ Initials avatars are aria-hidden; name is in text
✓ Reduced-motion support
✓ No hover-only information
✓ Inputs 16px (no iOS zoom)

12 / Guardrails & handoff

Rules.

Keep future pages inside the same family.

DO

Use the lime-yellow signal for the action, key numbers and the bold phrase in a headline. Keep surfaces charcoal-black. Let large condensed headlines and one slash shape carry the personality. Use real proof. Keep copy scannable. One primary CTA per context.

DON’T

Put a signal button on a signal surface. Use uppercase for long headings. Use more than one slash motif per screen. Turn every section into a card. Add a second accent color. Repeat “Book a free trial” after every section. Invent claims.

DO

Preserve form values after failure. Offer WhatsApp as the fallback. Show the avatar circle when there is no photo. Publish a testimonial only with consent and approval.

DON’T

Hide errors. Show a scheduled time that isn’t confirmed. Rely on a photo for a testimonial to work. Show private lead data anywhere public.
